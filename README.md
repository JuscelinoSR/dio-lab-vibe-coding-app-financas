## 📋 Sobre o Projeto

**Sereno** é um assistente financeiro conversacional que transforma a gestão de finanças pessoais em uma experiência natural e intuitiva. Desenvolvido com princípios de **Vibe Coding**, combina educação financeira preventiva, simplicidade de uso e acessibilidade universal.

### 🎯 Objetivo Principal
Facilitar o controle financeiro de forma simples, intuitiva e inclusiva, **eliminando a necessidade de planilhas ou formulários complexos**.

---

## ✨ Principais Funcionalidades

| Funcionalidade | Descrição |
|---|---|
| 💬 **Chat Interativo** | Conversa natural com o Agente Financeiro Sereno |
| 📝 **Registro Automático** | Compreende frases como "gastei 45 no mercado" |
| 💳 **Cálculo de Juros** | Simula parcelas e mostra custo total |
| 🎯 **Metas Financeiras** | Definição e acompanhamento de objetivos |
| ⚠️ **Alertas de Endividamento** | Avisa quando o orçamento é insuficiente |
| 💰 **Liquidação de Dívidas** | Identifica capital disponível para quitar débitos |
| 📊 **Relatórios Personalizados** | Visão clara dos gastos e progresso |
| ♿ **Design Universal** | Interface acessível, legível e inclusiva |

## 📖 Casos de Uso

### Exemplo 1: Registro de Despesa
```
Usuário: "Gastei 150 reais no supermercado ontem"
Sereno: "Registrei uma despesa de R$150 em Alimentação. 
        Seu saldo disponível agora é R$2.840. 
        Você está dentro do orçamento! 💚"
```

### Exemplo 2: Cálculo de Compra Parcelada
```
Usuário: "Quero parcelar um notebook de 3.000 em 12 vezes"
Sereno: "Com juros de 2% a.m., suas parcelas seriam:
        - Valor por parcela: R$272,30
        - Custo total: R$3.267,60
        - Juros: R$267,60
        Cabe no seu orçamento? 📊"
```

### Exemplo 3: Alerta de Orçamento
```
Usuário: "Vou gastar 2.000 em uma viagem"
Sereno: "⚠️ Atenção! Seu saldo livre é de R$1.500.
        Essa despesa geraria um déficit de R$500.
        Quer revisar o planejamento? 💭"
```

## 🎓 O Processo de Vibe Coding

### ✅ O que funcionou bem
- Estrutura clara do PRD, que guiou o desenvolvimento
- Experiência de conversa natural, tornando o uso intuitivo
- Inclusão de funcionalidades educativas (cálculo de juros, alertas)
- Colaboração eficiente com IA para ideação e prototipagem

### 🔧 O que não funcionou como esperado
- Necessidade de ajustes na interface para acessibilidade plena
- Alguns fluxos de conversa exigiram refinamento para evitar ambiguidades
- Balance entre funcionalidades e simplicidade

### 💡 Aprendizados Principais
- **Estrutura de Prompts**: A importância de estruturar bem os prompts para obter respostas úteis
- **IA como Parceira**: A IA pode ser uma parceira criativa no processo de design e prototipagem
- **Diálogo Iterativo**: O diálogo iterativo ajuda a evoluir rapidamente ideias e produtos
- **Design Inclusivo**: Acessibilidade deve ser pensada desde o início, não adicionada depois
