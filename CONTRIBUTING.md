# 🤝 Guia de Contribuição

Obrigado por seu interesse em melhorar o **Sereno**!

## Como Contribuir

### 1. 🧪 Testando o Protótipo
A melhor forma de contribuir é testar e fornecer feedback:

- Acesse [https://chat-cash-buddy-08.lovable.app/](https://chat-cash-buddy-08.lovable.app/)
- Teste diferentes cenários financeiros
- Anote comportamentos inesperados ou sugestões

### 2. 📝 Reportando Problemas

**Encontrou algo estranho?**

1. Descreva o problema com clareza
2. Inclua os passos para reproduzir
3. Explique o resultado esperado vs. atual
4. Compartilhe screenshots se possível

### 3. 💡 Sugerindo Funcionalidades

**Tem uma ideia brilhante?**

1. Descreva o caso de uso
2. Explique como isso ajuda usuários
3. Mostre exemplos de interação
4. Considere acessibilidade

### 4. ✍️ Melhorando Documentação

- Erros gramaticais? Avise-nos!
- Documentação confusa? Sugira melhorias!
- Exemplos faltando? Adicione-os!
